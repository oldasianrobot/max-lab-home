PARAMETER VALUE NOTES
Vortex geometry Instanced particle points ~3,000 pts desktop / 1,800 mobile. Positions computed via helical math on GPU using TSL position node.
Vortex animation useFrame + time uniform Particles rotate continuously on Y-axis. Speed: 0.3 rad/s. Always animating, all sections.
Camera arc (pivot) GSAP to() on camera.position Spherical interpolation from [0,12,0.1] to [12,1,0]. lookAt [0,0,0] throughout. 1200ms ease-out cubic.
Helix dimensions Radius 2u, Height 8u World units. Camera FOV 50° desktop fills viewport at these dimensions. 65° on mobile.
Particle color #E06C2A (Warm Oxide accent) Single color per palette spec. Opacity varies 0.2–0.9 by position along helix (brighter at core).
Post-processing C1 chroma + C2 scanline + C3 ghost C1+C3 via TSL post-process node. C2 CSS overlay div. All active on desktop. C1+C3 off on mobile.
Experiment cards HTML overlays, positioned in CSS NOT 3D objects. Absolute-positioned divs that animate in with Motion (translateX + opacity). Appear left/right of vortex column alternating.
